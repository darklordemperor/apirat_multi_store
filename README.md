# 🛒 Apirat Multi Store — Flutter E-Commerce App

A full-featured mobile E-Commerce application built with **Flutter** and **Firebase**, supporting both customer mobile app and web-based admin panel.

> ⚠️ Built with Flutter 2.x (2022) — may require dependency updates to run on current Flutter version.

---

## 📱 Features

### Customer App (Mobile)
- Browse and search products
- Add to cart and checkout
- User authentication (Sign up / Login)
- Profile management with image upload
- Real-time order tracking

### Admin Panel (Web)
- Create and manage products
- Manage orders and inventory
- Upload product images

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Mobile Framework | Flutter (Dart) |
| Backend & Database | Firebase Firestore |
| Authentication | Firebase Auth |
| File Storage | Firebase Storage |
| State Management | Flutter built-in |
| Image Picker | image_picker |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK 2.x
- Firebase project setup
- Android Studio / VS Code

### Installation

```bash
# Clone the repository
git clone https://github.com/darklordemperor/apirat_multi_store.git

# Navigate to project
cd apirat_multi_store

# Install dependencies
flutter pub get

# Run the app
flutter run
```

### Firebase Setup
1. Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com)
2. Add Android/iOS app and download `google-services.json`
3. Enable **Firestore**, **Authentication**, and **Storage**
